# Project Specification

## Overview

A fullscreen WebGL scene featuring an interactive 3D galaxy with a particle-based planet core, orbital photo tiles, and atmospheric elements. The experience is designed for both desktop and mobile platforms with responsive camera positioning.

## Core Features

### Visual Elements
- Central purple particle sphere
- Flattened orbital disk with concentric photo rings
- Distributed photo tiles at multiple scales and depths
- Starfield with white and lavender particles
- Diagonal meteor streaks
- 3D text overlay

### User Interaction
- Click/tap to proceed from initial modal
- Cinematic camera choreography
- Manual orbit controls
- Touch-compatible gestures
- Interactive photo tile details

### Technical Stack
- React with TypeScript
- Three.js for 3D rendering
- Canvas-based fullscreen experience
- Responsive design (desktop and mobile)
- Seeded geometry for consistency
- Sprite-based photo billboards

## Design Principles

- Black background with purple and white accents
- Physical 3D parallax and depth
- Deterministic particle placement
- Seamless responsive scaling
- Audio accompaniment
- Modal interface for initial interaction
